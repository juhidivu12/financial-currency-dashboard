# Financial Currency Dashboard

Interactive dashboard for analyzing historical currency exchange trends using Python, MySQL, and Apache Superset.

## Tech Stack
- Python
- Pandas
- MySQL
- Apache Superset

## Features
- Currency trend analysis
- Interactive visualizations
- SQL-based analytics
- Dashboard reporting

## Project Structure
financial-currency-dashboard/
│
├── data/
├── scripts/
├── README.md
├── requirements.txt
└── .gitignore

## How to Run
1. Create virtual environment
2. Install requirements
3. Upload dataset to MySQL
4. Run Apache Superset
